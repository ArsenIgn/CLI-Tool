# Конвертер конфигураций в XML — вариант №12

Программа читает конфигурацию в UTF-8 из стандартного ввода, разбирает её
грамматикой **pyparsing**, вычисляет константы и записывает XML в UTF-8.
Требуется Python 3.10 или новее.

## Установка и тестирование

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Сборка не требуется. В Linux и macOS вместо `python` можно использовать
`python3`.

## Запуск

Ключ `-o ПУТЬ` (или `--output ПУТЬ`) обязателен. Путь может быть
абсолютным или относительным к текущей папке. При успешном преобразовании
существующий файл по указанному пути перезаписывается.

**Linux / macOS**

```sh
./run.sh -o server.xml < examples/server.conf
./run.sh --output library.xml < examples/library.conf
```

**Windows PowerShell**

```powershell
cmd /c '.\run.bat -o server.xml < examples\server.conf'
cmd /c '.\run.bat --output library.xml < examples\library.conf'
```

## Синтаксис

| Конструкция | Синтаксис | Пример |
| --- | --- | --- |
| Число | `[1-9][0-9]*` | `8080` |
| Строка | Текст в одинарных кавычках | `'Городская библиотека'` |
| Массив | `({значение, значение})` | `({3, 'api.local'})` |
| Словарь | `dict(Имя = значение, Имя = значение)` | `dict(Port = 8080)` |
| Имя | `[_A-Z][_a-zA-Z0-9]*` | `_Port` |
| Объявление константы | `Имя is значение;` | `_Port is 8080;` |
| Ссылка на константу | `$Имя$` | `$_Port$` |

Документ содержит ноль или больше объявлений и одно итоговое значение.
Константы вычисляются сверху вниз. Ссылка может указывать на ранее
объявленную константу, включая массив или словарь. Повторное объявление
константы считается ошибкой. Массивы и словари могут быть пустыми и
вкладываться друг в друга. Завершающая запятая и экранирование кавычек в
строках грамматикой не предусмотрены.

## Формат результата

Корневой элемент — `<config>`. Числа и строки представлены как
`<number>` и `<string>`. Каждый элемент `<array>` оборачивается в
`<item>`, а каждая запись `<dict>` — в `<entry name="...">`. В XML
попадают вычисленные значения констант. Объявления служат для вычисления
и отдельно в XML не записываются.

Например, вход `Port is 8080; dict(HttpPort = $Port$)` даёт такой XML
(заголовок опущен):

```xml
<config>
  <dict>
    <entry name="HttpPort">
      <number>8080</number>
    </entry>
  </dict>
</config>
```

В `examples/server.conf` заданы порт, разрешённые хосты и число рабочих
процессов веб-сервера. В `examples/library.conf` заданы филиалы и условия
выдачи печатных и электронных книг.

## Функции проекта

- `build_parser()` задаёт грамматику и создаёт парсер.
- `convert(source)` разбирает входной текст, вычисляет объявления в
  порядке следования и возвращает XML в виде байтов.
- `render(node, constants, source)` строит элементы XML рекурсивно и
  подставляет значения констант.
- `main()` читает stdin, обрабатывает аргументы и сохраняет результат.
  Диагностика идёт в stderr. При ошибках входного текста выводятся
  строка и столбец. Код завершения — 0 при успехе, 1 при ошибке данных
  или ввода-вывода и 2 при ошибке аргументов.
